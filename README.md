# 📝 Todoo App

A beautiful and functional Todo application built with Flutter, designed to help you organize and manage your daily tasks efficiently.

## 🌟 Features

- ✅ Add, edit, and delete tasks
- 📅 Organize your daily activities
- 🎨 Clean and intuitive user interface
- 📱 Responsive design that works on all devices
- 💾 Local storage for your tasks

## 📱 Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK
- Any IDE with Flutter plugin (VS Code, Android Studio, IntelliJ)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abhishek786216/Todoo-app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Todoo-app
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Run the app:
   ```bash
   flutter run
   ```

## 🌐 Web Deployment

This app is deployed using GitHub Pages. To deploy your own version:

1. Build for web:
   ```bash
   flutter build web --base-href "/Todoo-app/"
   ```

2. Deploy to GitHub Pages using the `gh-pages` branch.
